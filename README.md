# E-Commerce Sentiment Analysis & Defect Diagnostics
24INFS7101 NLP & Text Analytics in Business, A2 Capstone.

Aspect-based sentiment analysis (ABSA) of Flipkart consumer-electronics reviews: 10,004 cleaned verified-purchase reviews, 92 products, 5 categories. It shows which product aspect (battery, build, comfort, customer service and so on) drives negative sentiment in each category.

## Folder layout
- `data/flipkart_raw.csv` : raw scraped reviews (23,046 rows)
- `data/flipkart_reviews.csv` : cleaned dataset used by the notebook
- `data/flipkart_cleaning_log.json` : counts for every cleaning step
- `data/collect_flipkart_reviews.py` : rebuilt collection script (see Work log, 23 Oct)
- `data/build_flipkart_csv.py` : cleans the raw file: `python3 data/build_flipkart_csv.py data/flipkart_raw.csv data/flipkart_reviews.csv`
- `data/negative_mentions_manual_audit_flipkart.csv` : hand-read sample of 80 Negative labels
- `notebooks/ABSA_Capstone_Flipkart.ipynb` : the analysis; `build_notebook_flipkart.py` rebuilds it (reads `insights_flipkart.md`, `limitations_flipkart.md`, `clean_markdown.py`)
- `outputs_flipkart/` : result tables, figures and the dashboard

## How to run
1. Python 3.10+. Open the notebook and Run All; the first cell installs the libraries and language data with `!pip`.
2. Random seeds are fixed (42), so results match the report with the same data.

## Notes
- The sample is not random (recent, negative-first and most-helpful views of each product page), so compare aspects with each other rather than quoting overall percentages.
- The 80-mention audit file was a first pass; please re-check it as a team.
- Reports and presentations are in `documents/`, which is git-ignored.

### 14 Oct 2026: Data collection
- Collected verified-purchase reviews from Flipkart's public product review pages with a one-off script run in a browser session (no login, no CAPTCHA bypass, about 3 page requests per second; reviewer names not saved).
- Products: searched Flipkart for 16 electronics product types; 36 products picked by hand plus 96 from search results = 132 listings.
- For each product, read three views of the review list: most recent (up to 8 pages), negative first (up to 5 pages) and most helpful (up to 8 pages), 10 reviews per page.
- Output: raw dump files (`flipkart_raw.psv`, `flipkart_raw2.psv`, values separated by `|`), 23,046 review rows. The browser script itself was not saved.

### 14-15 Oct 2026: Cleaning and first analysis

Result: 10,004 reviews, 92 products, 5 categories.

### 23 Oct 2026: Rebuilt collection script
- Wrote `data/collect_flipkart_reviews.py`, a rebuilt version of the collection step, because the original browser script from 14 Oct was not saved. It is not the exact code that produced `data/flipkart_raw.csv`.
- It takes the product list from `data/flipkart_raw.csv`, opens each product's public review pages in a normal Chromium window (Playwright) in the same three views (recent up to 8 pages, negative first up to 5, most helpful up to 8), reads rating, title, text, date, helpful votes and certified-buyer mark (no reviewer names), and writes the same `|`-separated raw format.

- Run: `pip install playwright pandas`, `python -m playwright install chromium`, then `python data/collect_flipkart_reviews.py --test` (one product) and the full run with `--out data/flipkart_raw_recollected.psv`.
- Not yet tested against the live Flipkart site; Flipkart changes its page layout often, so check the test output first.
